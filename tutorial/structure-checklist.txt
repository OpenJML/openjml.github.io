Every topic N should have:

0. A link to N in index.md
1. A tutorial chapter named N.md in this directory (tutorial).
2. An entry in exercises/exercises.md
   (structured the same as index.md here), probably of the form:
   "  * [N](N)"
   with the first "N" possibly being an appropriate English phrase.
3. Some exercises in exercises/NEx.md
   a. starting with a title of "title: JML Tutorial - Exercises - N"
   b. A first level heading of the form "# N Exercises:"
   c. A second level heading of the form: 
      "## [N tutorial](https://www.openjml.org/tutorial/N)"
   d. a numbered list of questions, with each one having:
      (i). A second level heading "## **Question 1**" ...
           (be sure there are no spaces after the "**"
      (ii). A boldfaced (**) question, with code named "NEx1.java",
            if appropriate, starting with the comment line:
	    "// openjml --esc NEx1.java"
      (iii). If the question is about an entire class or interface,
             use "```Java
	          {% include_relative NEx1.java %}
		  ```"
	     to include the source file
      (iv). A file named "NEx1.out" if the code for NEx1.java has any
            verification errors, with any such
            verification errors indicated by a comment at the end of
	    the line of the form: "   // ERROR: ..."
            (with "..." giving some reason that doesn't make the
	    question trivial.
    e. a paragraph (or list) starting with "**Learning Objectives:**
    f. A second-level heading of the form
       "## **[Answer Key](NExKey)**"
    g. A second-level heading of the form
       "## Resources"
       followed by a list of relevant resources,
       including links to any Java code of the form
       "+ [NEx1 Java code](NEx1.java)
4. An answer key in exercises/NExKey.md with:
   a. a title of the form "title: JML Tutorial - Exercises - N"
   b. a first level heading of the form:
       "# N Exercises Key:"
   c. a second level heading linking to the tutorial section
      of the form: 
      "## [N tutorial](https://www.openjml.org/tutorial/N)"
   d. a numbered list of answers to the questions,
      with each having:
      (i). An introductory sentence or paragraph,
      (ii). Java + JML that solves the exercise,
            from the file NEx1Ans.java, pasted into NExKey.md
	    between ```Java
	    and     ```
	    with the comment to run OpenJML removed and
	    with NEx1Ans replaced everywhere by NEx1
      (iii). The NEx1Ans.java file should verify,
             but if it does not, there should be an NEx1Ans.out
	     file created by executing "make NEx1Ans.out"
      (iv). Any additional explanation or thoughts on the question or solution.
   e. a second level heading of the form:
      "## Resources"
      followed by a list including any relevant resources,
      with at least the following:
      "+ [N Exercises](NEx)
       + [All exercises]((https://www.openjml.org/tutorial/exercises/exercises)
      "
